# Contributing Guidelines

Thank you for your interest in contributing to Awesome Creator Economy. Your suggestions help this list stay useful and current.

## Quality Standards

This list is curated, not exhaustive. We follow the [Awesome Manifesto](https://github.com/sindresorhus/awesome/blob/main/awesome.md). Entries must be:

- **Actively maintained.** No abandoned projects.
- **Useful.** A creator, seller, or buyer must benefit from using it.
- **Specific.** Generic tools without a clear creator-economy use case will be rejected.
- **Honest.** No fake reviews, deceptive pricing, or scammy products.

## How to Add an Entry

1. **Fork this repository.**

2. **Find the right section** for your entry. If unsure, open an issue first to discuss the best fit.

3. **Add your entry in alphabetical order** within the section, except for sections that explicitly note otherwise.

4. **Use this exact format:**

   ```markdown
   - [Name](URL) - One-sentence description ending with a period.
   ```

   - The name must match the official product name.
   - The URL must point to the product's homepage, not an affiliate or tracked link.
   - The description must be a single sentence, end with a period, and avoid marketing buzzwords like "revolutionary," "world's best," or "game-changing."
   - Keep descriptions under 25 words.

5. **Open a pull request** with a clear title and a short explanation of why the entry fits this list.

## What Gets Rejected

- Affiliate or tracked links.
- Inactive or abandoned products (no updates in 12+ months).
- Self-promotion without genuine value to readers.
- Duplicate entries already on the list.
- Entries with marketing language or hype.
- Products that don't serve creators, sellers, or buyers in the digital economy.
- Products with clearly poor reputation, scammy pricing, or unethical practices.

## Pull Request Format

Please structure your PR description like this:

```markdown
**What:** Brief description of the product.
**Section:** Which section you added it to.
**Why it fits:** Why this product belongs on the list.
**Disclosure:** Are you affiliated with this product? (We accept self-submissions but require disclosure.)
```

## Updates and Removals

- If a product changes name, URL, or scope, please open a PR to update it.
- If a product becomes abandoned or unethical, please open an issue or PR to remove it.

## Suggesting New Sections

If you want to suggest a new category, open an issue first. We'll discuss whether it fits the scope of this list before merging changes.

## Code of Conduct

Be respectful in issues, PRs, and discussions. We follow the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Harassment, spam, or bad-faith arguments will result in a ban.
